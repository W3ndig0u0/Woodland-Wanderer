# Woodland Wanderer 🌲🏃‍♂️

An atmospheric **2D Platformer** built in Unity for an university project. Embark on a journey through a mysterious woodland world, featuring precise movement and classic platforming challenges.

## 🎮 Play Now
Experience the game directly in your browser:
**[Play on itch.io](https://w3ndig0u0.itch.io/woodland-wanderer)**

## ✨ Features
*   **Fluid Movement**: Responsive jumping and running mechanics tuned for a satisfying feel.
*   **Hand-Crafted Levels**: Navigate through dangerous terrain and environmental obstacles.
*   **Atmospheric Art**: A cohesive 2D aesthetic designed to immerse the player in the forest setting.
*   **Smooth Performance**: Optimized for both web-GL and desktop builds.

## 🛠️ Tech Stack
*   **Engine**: Unity 2D
*   **Language**: C#
*   **Physics**: BoxCollider2D & Rigidbody2D implementation for tight collision.
